# Takraw Stats Indonesia

Platform notational analysis sepak takraw: pencatatan per sentuhan, statistik tim dan atlet, agenda kejuaraan.
Aturan mengikuti ISTAF Law of the Game 2024 (Regu, Double, Quadrant).

- Pengunjung: beranda, agenda, regulasi.
- Daftar dengan email & kata sandi untuk mencatat pertandingan. Hasil dan statistik terbuka setelah akun disetujui pemilik platform.

Bukan situs resmi ISTAF maupun PSTI.
